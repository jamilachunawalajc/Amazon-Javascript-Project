# Amazon JavaScript Project

A JavaScript-focused Amazon-style e-commerce project built to practice working with dynamic web pages and interactive features.

## About

In this project, I focused mainly on the JavaScript functionality. The product HTML is generated dynamically using JavaScript instead of writing each product directly in HTML.

The project uses product data and JavaScript modules to display products and manage the shopping cart.

## Features

* Dynamically displays products using JavaScript
* Product information is generated from JavaScript data
* Add products to cart
* Updates cart quantity
* Product ratings and prices are displayed dynamically
* Uses JavaScript modules with `import` and `export`
* Separate files for product data, cart functionality, and utility functions

## Technologies Used

* HTML
* CSS
* JavaScript
* ES6 Modules

## What I Practiced

* DOM manipulation
* Template literals
* Arrays and objects
* Functions
* Event listeners
* `import` and `export`
* Working with separate JavaScript files
* Building basic shopping cart functionality

## Note

This project is mainly focused on practicing JavaScript and its functionality. The existing HTML/CSS structure was used as the base, while the product content and interactive features were generated and handled using JavaScript.
